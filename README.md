# RingToneMaxxxing — Official Website & Staging Portal 🎵📱

Official landing website and APK staging portal for **RingToneMaxxxing**, an Android application that dynamically rotates ringtones for every incoming call and assigns dedicated tones to VIP contacts.

Built with a tactile **Claymorphism** design system, crafted with warm terracotta and sage tones, soft 3D puffy surfaces, interactive audio playback previews, and fluid micro-interactions.

---

## ✨ Features Highlighted on the Site

- 🔀 **Dynamic Incoming Call Playlist Rotation**: Cycles through custom audio files on every call.
- 👤 **Fixed Contact Assignment**: Assigns custom ringtones to specific contacts with Room database fallback.
- 🔒 **100% Offline & Privacy-First**: Zero cloud tracking, no ads, no analytics SDKs, and zero internet permissions in the Android Manifest.
- 📂 **Universal Audio Engine**: Supports MP3, WAV, OGG, M4A, AAC, and FLAC.
- 🛡️ **Native Lock Screen Integration**: Operates seamlessly via Android's native `RingtoneManager` with zero audio delays even in deep Doze mode.
